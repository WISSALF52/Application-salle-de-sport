# Application de Gestion d'une Salle de Sport

## Description

Ce projet est une application de gestion d'une salle de sport, développée pour aider les propriétaires de salles de sport à gérer efficacement leurs installations, membres, cours et autres ressources. L'application permet de suivre les inscriptions des membres, planifier les cours, gérer les équipements et bien plus encore.

## Fonctionnalités

- **Gestion des Membres** : Inscription des nouveaux membres, suivi des abonnements, gestion des paiements.
- **Planification des Cours** : Création et gestion des horaires de cours, inscriptions aux cours.
- **Gestion des Équipements** : Suivi et gestion des équipements de la salle de sport.
- **Rapports** : Génération de rapports sur l'utilisation des installations, les inscriptions, les paiements, etc.

## Technologies Utilisées

- **HTML** : Utilisé pour structurer le contenu de l'application.
- **CSS** : Utilisé pour le design et la mise en forme de l'application.
- **Java** : Utilisé pour la logique de l'application et le traitement des données.
- **Spring Boot** : Utilisé pour le développement de l'application avec Java.
- **Maven** : Utilisé pour la gestion des dépendances et la construction du projet.
- **Teamlyf** : Utilisé pour la collaboration en équipe et la gestion des tâches.
- **Docker** : Utilisé pour la conteneurisation de l'application.
- **Jenkins** : Utilisé pour l'intégration continue et le déploiement continu (CI/CD).

## Installation

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/errachidy10/Application-salle-de-sport-main1.git
   ```
2. Naviguez dans le répertoire du projet :
   ```bash
   cd Application-salle-de-sport-main1
   ```
3. Compilez et exécutez l'application :
   ```bash
   mvn clean install
   mvn spring-boot:run
   ```

## Utilisation de Docker

1. Construisez l'image Docker.
2. Exécutez le conteneur Docker.
